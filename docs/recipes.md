# ZedComm crafting recipes

Every recipe is in the crafting menu under ZedComm. Recipes marked with a screwdriver need one in the inventory and do not use it up. Electrical is the skill level required; a dash means none. XP is the base Electrical award per craft.

Wire means the roll of wire, which holds 10 units; amounts of it are in units. One unit can be used wherever a recipe asks for one Electric Wire.

This file is written by `tools/make-recipes.py`. Change recipes there, not here.
